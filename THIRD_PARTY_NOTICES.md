# Third-party notices

This integration ports to JavaScript the knowledge of the NASweb local API
held by the following project: its endpoints, the bodies it sends (the
SHA-1 of the password included), the shape of the status the module pushes
and how it is read. No code is copied, and nothing of it is installed at
runtime; its notice is reproduced as a credit.

The mapping of the outputs, inputs and temperature also follows Home
Assistant's NASweb integration (`homeassistant/components/nasweb`,
Apache-2.0), read, not copied.
